deliBEE UI/UX sampler

A one-page snapshot of the marketplace interface: the colour and type tokens, the core components, and the page patterns the app already uses. Open it in any browser — it needs no Laravel, no Node and no build step. The full Blade and CSS source lives in samples/ if the team wants to edit the real files.

Static HTML + CSS Light & dark Fredoka + Inter WCAG 2.2 AA text pairings Tokens from resources/css/app.css
How to use this page. Treat it as the visual contract for the existing screens. When a component is reworked, match the token names in theme/tokens.css and keep the light/dark pairs together. The running app is the final reference for behaviour; this kit only covers how things look.
01

Colour

A cream paper base, ink text and a single honey accent. Honey is a surface and highlight colour, never body text. The warm zinc scale replaces Tailwind's default zinc everywhere.

Contrast rule. Zinc 500 is the lightest tone allowed for muted text on paper (5.05:1). Zinc 400 is reserved for dark mode and decorative marks. Never put ink text on honey deep, or honey text on paper.

03

Buttons

One primary action per area. Primary buttons are ink that turn honey on hover; secondary buttons are quiet outlines for the alternative path; text links are for in-flow actions.

Browse the marketplace See the BeeRank All orders
Unlist

Hover: primary flips to honey with ink text; secondary darkens its border. Disabled: 50% opacity, no pointer. Focus: 2px honey-deep outline with a 2px offset.

04

Form controls

Labels sit above the control in 12px zinc. Inputs use paper-tinted fields with comb borders and a honey focus ring. The filter bar below is the exact marketplace pattern.

Error text is red-600 in light mode and red-300 in dark mode; do not rely on colour alone — keep the message.

05

Badges & status pills

Status pills are the only place saturated tints appear. Each has a matching dark-mode variant that keeps text contrast intact.

Empty state

Dashed comb outline, one display line, one helpful sentence and a single way out. The same pattern covers an empty cart, no orders and a filtered marketplace with no results.

Footer

The footer is the only full ink block on the storefront. Keep it quiet: one brand mark, one sentence, two links that warm to honey on hover.
